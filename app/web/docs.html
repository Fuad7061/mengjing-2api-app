概览

本服务把「AI梦境画画师」App 的文生图能力封装为 OpenAI 兼容的 HTTP 接口，底层调用阿里云百炼 qwen_image3 模型。所有请求默认需要携带 API 密钥。

项目值
Base URL-
鉴权方式Authorization: Bearer <API_KEY> 或 x-api-key
响应格式JSON（UTF-8）
单张耗时约 50–60 秒

POST /v1/images/generations 文生图

{
  "prompt": "一只白色的猫，坐在窗台上，阳光洒落",
  "size": "1024x1024",   // 可选：1024x1024 | 768x1344 | 1344x768
  "style": "二次元"       // 可选，默认「二次元」

其他接口

方法路径说明
GET/v1/models可用模型列表
GET/v1/styles支持的画风列表
GET/v1/pool账号池状态
GET/health健康检查（无需鉴权）

尺寸与画风

  • 1024x1024 正方形
  • 768x1344 竖版
  • 1344x768 横版

Python 示例

import requests

r = requests.post(
    "BASE/v1/images/generations",
    headers={"Authorization": "Bearer API_KEY"},
    json={"prompt": "赛博朋克城市夜景", "size": "1344x768", "style": "赛博朋克"},
    timeout=180,
)
print(r.json()["data"][0]["url"])

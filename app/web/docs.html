Overview

This service wraps the text-to-image capability of the "AI梦境画画师" app as an OpenAI-compatible HTTP API, backed by Alibaba DashScope qwen_image3. Requests require an API key by default.

ItemValue
Base URL-
AuthAuthorization: Bearer <API_KEY> or x-api-key
Response formatJSON (UTF-8)
Latency~50–60 seconds per image

POST /v1/images/generations text to image

{
  "prompt": "A white cat on a windowsill, sunlight streaming in",
  "model": "qwen-image3",         // optional
  "style": "Anime",               // optional, default "Anime"
  "aspect_ratio": "16:9",         // optional: 1:1 | 9:16 | 16:9
  "size": "1024x1024",            // optional: 1024x1024 | 1024x1792 | 1792x1024 | 512x512
  "n": 1,                          // optional: 1-4 images
  "response_format": "url"        // optional: "url" (default) | "b64_json"
}

aspect_ratio takes precedence over size when both are given. Each requested image consumes one credit and takes ~50–60s, generated sequentially.

Python example

import requests

r = requests.post(
    "BASE/v1/images/generations",
    headers={"Authorization": "Bearer API_KEY"},
    json={"prompt": "cyberpunk city at night", "aspect_ratio": "16:9", "style": "Cyberpunk"},
    timeout=180,
)
print(r.json()["data"][0]["url"])
